## Суть проекта
Сервис для отслеживания инвестиционного портфеля на данных Московской биржи.
- Источник данных: ISS API Мосбиржи — https://iss.moex.com (JSON, без ключа; данные отложенные).
- Свой REST API: портфели, позиции (тикер + количество), текущая стоимость портфеля, доходность.
- Фоновая загрузка котировок и свечей из ISS, хранение истории в PostgreSQL.

## Стек
- Go 1.26+, `net/http` со встроенным роутингом (`GET /portfolios/{id}`)
- PostgreSQL в `docker compose`, драйвер `pgx`, запросы через `sqlc`
- Миграции: `goose`
- Логи: `log/slog`
- Деньги: `numeric` в БД, `shopspring/decimal` в Go — никакого `float64`
- Тесты: `httptest` (свои хендлеры и подмена ISS), `testcontainers-go` для БД

## Модуль и структура
Модуль: `github.com/ASM717/moex-portfolio`

```
cmd/server/        точка входа, ручная сборка зависимостей (без DI-контейнера)
internal/
  portfolio/       портфели и позиции: handler / service / repository
  quote/           котировки и свечи, хранение истории
  moex/            HTTP-клиент к ISS
migrations/
docker-compose.yml
```

## Нюансы ISS API
- Ответ табличный: `columns` и `data` приходят отдельными массивами — нужен свой маппинг в структуры.
- Пагинация через параметр `start`.
- Разные рынки и режимы торгов (акции, облигации, валюта) — разные эндпоинты.
- HTTP-клиент обязательно с таймаутом.

## Конвенции
- `context.Context` первым аргументом во всех вызовах с I/O.
- Интерфейсы объявляются на стороне потребителя, а не реализации.
- Ошибки оборачивать через `fmt.Errorf("...: %w", err)`, проверять через `errors.Is/As`.
- Имена пакетов короткие, в нижнем регистре, без подчёркиваний.
